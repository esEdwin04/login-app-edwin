# login-app-edwin

Formulario de inicio de sesión (HTML, CSS y JavaScript) - Edwin Diaz Arrieta - CECAR.

## Estrategia de ramas: GitHub Flow
- `main` siempre estable y desplegable.
- Cada funcionalidad nace en una rama corta (`feature/...`) y se integra por Pull Request revisado por un compañero.
- Justificación: equipo pequeño, entregas frecuentes y poca ceremonia; Git Flow añade ramas que no necesitamos y trunk-based exige una batería de pruebas que aún no tenemos.

## Convención de commits
Conventional Commits: `feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `ci:`.
